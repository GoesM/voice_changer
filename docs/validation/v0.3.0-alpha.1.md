# v0.3.0-alpha.1 验证记录

日期：2026-10-28。Windows 开发机，Python 3.12。

## 本轮已测

- 31 项自动化测试通过。新增素材名与实际文件隔离、待确认录音不计入训练、确认后恢复进度、移除后重置完成状态、短录/静音/削波拒绝、重录失败保留旧录音、重录成功不重复计时、复制不包含模型及待确认音频、清单路径逃逸拒绝、文字发布包白名单检查。
- 40 段稿件的原始文字与 JSON 一致，稳定 ID 无重复，共 4,898 个汉字。15.3–20.4 分钟来自每分钟 240–320 字的估算，不是人类朗读计时。
- `scripts/smoke_reading_ui.py` 使用真实 Tk 控件和模拟音频，通过打开稿件、录制、停止、试听调用、确认入库、切到下一段、关闭恢复和素材库更新流程。未打开麦克风或实际播放声音。
- 旧版训练生命周期测试原先依赖测试机空闲磁盘容量；本轮隔离为固定模拟值，保留产品的真实空间检查。
- 本地 Windows PyInstaller 构建与 EXE 自检通过；冻结程序能读取 40 段稿件及其许可。文字 ZIP 生成成功，仅含三个白名单文件。

# v0.2.0-alpha.1 验证记录

日期：2026-10-25。开发机：Windows 11、Intel i9-13900HX、NVIDIA RTX 4060 Laptop 8 GB。

## 已测

- 17 项自动化测试通过：原有音频安全检查，加上静音/削波分析、项目名称路径隔离、素材不足拒绝、退出码为零但无产物时拒绝、取消后不入库及损坏组件拒绝。
- Tk 主界面和音色工作室构造、初始化、关闭通过；工作室请求高度 716 px。
- Windows PyInstaller 可执行包构建及原有 packaged DSP 自检通过；新资源包含检查仍在本轮最终构建中验证。
- 训练依赖在 Windows Python 3.12 解析成功，共 121 项固定版本依赖。真实安装与 GPU 链路验证进行中，完成后更新本记录。

## 尚未验收

- 真实目标说话者 10–20 分钟素材训练、中文自然度/相似度盲测、新女声预置筛选。
- 腾讯会议和 VALORANT 远端通话、反作弊共存、完整声学延迟、长时间游戏负载。机器尚未安装 VB-CABLE，因此不能宣称目标应用已通过。
- 驱动真实安装/UAC拒绝/重启闭环、新用户易用性、不同 GPU 和低显存配置。
- 素材噪声、混响、多人自动检测；目前只有音量与时长门槛。

## 交付边界

本版是实验性实现，不等于 PRD 中每个 P0 目标均验收完成。云训练明确延期。没有新增通过自然度盲测的官方预置；现有 Beatrice 是基线，自定义 RVC 是新增路线。模式参数不同，但不能将音频分块或推理耗时当成完整链路延迟。

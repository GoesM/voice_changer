# v0.2.0-alpha.1 验证记录

日期：2026-10-25。开发机：Windows 11、Intel i9-13900HX、NVIDIA RTX 4060 Laptop 8 GB。

## 已测

- 22 项自动化测试通过：原有音频安全检查，加上静音/削波分析、项目名称路径隔离、素材不足拒绝、退出码为零但无产物时拒绝、取消后不入库及损坏组件拒绝。
- Tk 主界面和音色工作室构造、初始化、关闭通过；工作室使用可滚动布局，关闭时清理定时器。
- Windows PyInstaller 可执行包构建及原有 packaged DSP 自检通过；GitHub Windows CI 两次通过，包括新增 worker 与依赖清单的打包资源检查。
- 训练依赖在 Windows Python 3.12 解析成功，共 121 项固定版本依赖。独立 Python 3.12.11、121 项依赖、基础模型实际安装完成；CUDA 检查识别 RTX 4060。完整合成信号训练与推理链路已通过。

- 官方 VB-CABLE Pack45 的 SHA-256、安全解压、Authenticode 签名验证通过；未启动安装器。修复 PowerShell 7 环境变量污染系统 PowerShell 5.1 模块路径的问题。

## 真实引擎集成验证

使用 `scripts/smoke_training.py`，在含中文的路径下生成 32 秒非语音合成信号，执行预处理、RMVPE 音高/ContentVec 特征提取、GPU 训练 1 轮（9 steps）、索引导出、离线加载自检及两模式各 50 块推理。进程退出码 0，输出长度正确、数值有限且非静音。没有录制麦克风、没有上传素材，测试模型不进入用户音色库。修复了 FAISS Windows 中文路径的文件读写问题。

| 模式 | 分块 | 处理 p95 | 处理最大值 | 块数 |
| --- | --- | --- | --- | --- |
| 游戏 | 100 ms | 48.27 ms | 54.42 ms | 50 |
| 会议 | 200 ms | 48.99 ms | 50.26 ms | 50 |

计时包含父进程到推理进程的通信，不含模型启动、采集、分块等待、虚拟声卡及目标应用，不是端到端延迟。合成信号的一轮训练只能证明工程流程可运行，不能证明真人音质。

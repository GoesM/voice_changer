# Voice Changer v0.2.0-alpha.1

Windows 11 实验性预览版：加入本地自定义音色工作室及更直接的首次配置入口。

- 应用内下载、SHA-256 校验及数字签名检查 VB-CABLE，启动官方安装器；管理员授权与重启由 Windows / 官方安装器处理。
- 独立本地训练环境自动安装，分段录音、WAV 导入、音量质检、试听和删除。
- Applio RVC 本地预处理、特征提取、训练、索引导出和离线自检，成功后音色出现在主界面。
- 自定义音色提供游戏/会议两套实际推理配置；云训练显示“功能仍在开发中....”。
- 后台加载模型，失败不输出原声；训练可取消，保留素材及检查点。

下载 `VoiceChanger-0.2.0-alpha.1-win-x64.zip`，完整解压运行 VoiceChanger.exe。无需手动安装 Python。新功能需要在应用内按需下载数 GB 环境和基础模型；NVIDIA CUDA 显卡是本版自定义音色前提。官方 Beatrice 音色仍可使用原有 CPU 路线。

本版未承诺真人自然度提升、腾讯会议/VALORANT 实机兼容或完整延迟达标。详细实测和未测范围见仓库 `docs/validation/v0.2.0-alpha.1.md`。本版程序未代码签名；不包含第三方模型、录音或驱动二进制。

验证：22 项自动化测试通过；Windows 构建与资源自检通过；RTX 4060 上完整执行合成信号单轮训练、中文路径索引导出和双模式离线推理。该测试不代表真人自然度或目标应用通话验收。

# Voice Changer v0.1.0 — Windows 技术预览

下载 `VoiceChanger-0.1.0-win-x64.zip`，完整解压运行 `VoiceChanger.exe`，无需 Python。`SHA256SUMS.txt` 用于核对完整性。

首次使用：[配置教程](https://github.com/GoesM/voice_changer/blob/main/docs/user/QUICKSTART.md)。安装官方 VB-CABLE，通过应用获取官方 Beatrice 插件和女声模型，配置 CABLE Input → CABLE Output。

包含中文 UI、本地 AI 男声转女声、模型下载和校验、音调/共振峰、耳机监听、静音、配置保存和诊断。

技术预览：腾讯会议/瓦洛兰特实际通话、中文自然度、两小时稳定性仍待验收。处理耗时不是完整延迟；程序未签名。模型、插件和驱动按各自条款获取，不捆绑分发。

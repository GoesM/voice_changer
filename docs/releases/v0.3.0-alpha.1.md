# Voice Changer v0.3.0-alpha.1

本版加入素材集管理与原创中文稿件引导录音。

- 素材集可直接选择、重命名、复制为新训练项目；兼容已有项目。
- WAV 素材显示可读名称、时长和来源，可试听、重命名、移除。
- 内置 40 段、4,898 汉字的原创中文稿件，估计 15–20 分钟；支持逐段录制、试听、确认、重录、跳过和下次继续。
- 待确认录音不进入训练集；重录失败不覆盖原素材，确认替换不重复计算时长。
- 云训练仍未开放，日常变声继续离线。

下载 `VoiceChanger-0.3.0-alpha.1-win-x64.zip`，完整解压运行 `VoiceChanger.exe`。应用已内置稿件，无需另外下载文字包。

同时发布 `VoiceChanger-ReadingKit-0.3.0-alpha.1.zip`，仅包含原创文字稿件及 CC0 许可，适合离线阅读或另行采集。**不含明星录音、用户录音或模型。**

[素材与朗读教程](https://github.com/GoesM/voice_changer/blob/main/docs/user/MATERIALS_AND_READING.md) · [首次使用](https://github.com/GoesM/voice_changer/blob/main/docs/user/QUICKSTART.md)

此版本仍为实验性预览；稿件预计时长不等于实际录音时长，音量门槛不等于音质认证。真人自然度、完整延迟及腾讯会议/VALORANT 兼容尚未完成实机验收。详细已测/未测范围见仓库验证记录。

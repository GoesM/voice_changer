# v0.3：素材集与原创稿件引导采集

日期：2026-10-28。用户确认：暂时没有明星录音的再分发和训练授权，先支持用户导入，发布原创朗读稿和采集功能。继承 Windows 11、离线音频处理、GitHub 管理与发布约束。

## 交付范围

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| M01 | 素材集列表与单一说话人组织 | 旧版项目可发现、可重命名、可复制为新训练项目 |
| M02 | 用户素材管理 | WAV 导入、保留可读名称、时长和来源、试听、重命名、移除；不移动源文件 |
| M03 | 原创中文稿件 | 40 段、至少 4,500 汉字；应用内置，Release 提供独立文字包和许可 |
| M04 | 逐段引导采集 | 显示稿件、录音、停止、试听、确认、重录、跳过、选择段落 |
| M05 | 可恢复进度 | 重开后恢复当前位置、已确认段落、待确认录音；删除素材后同步完成状态 |
| M06 | 防止无效录音入库 | 待确认录音隔离；短录、削波、过低有效声音拒绝确认；重录失败保留旧素材 |
| M07 | 实际时长验收 | 继续沿用训练的总时长/有效声音门槛，不把字数估算或读完稿件当成达标 |
| M08 | GitHub 发布 | Windows 应用、文字稿件包、两个文件的 SHA-256；README 和教程更新 |

## 边界

本版不收集或分发未授权的明星录音，不创建空的明星素材占位。未来取得授权后再定义音频素材包分发、授权信息及下载校验流程。本版文字包不是音频素材包，也不是声音模型。

每个现有音色项目同时作为一个素材集；复制素材集创建新的训练项目，保持旧模型可用。旧版文件无需批量迁移，首次浏览时生成可读索引。移除素材使用项目内回收目录，不影响原始导入文件或已训练模型。

引导录音采用“录制 → 待确认 → 试听 → 用户确认 → 检查 → 入库”，关闭窗口保留已停止的待确认录音。重录未通过不能替换旧录音。录音超 3 分钟自动停止；突然断电或强制杀进程不保证尚在录制的 WAV 可恢复。

不新增云训练、语音识别、自动文本对齐或 MP3 转码。不宣称稿件具有经过研究验证的音素平衡，也不承诺录完即可达到真人自然度。真实麦克风体验与真人训练效果需另行验收。

# 首版验收计划

日期：2026-10-24 | 对应 PRD：v0.2 | 状态：计划，全部未执行

本计划用于把用户已确认的核心范围转化为可追踪证据；性能阈值仍是 PRD 中的候选值，正式验收前需要冻结。

## 测试记录要求

记录代码/安装包版本、模型及校验值、驱动版本、Windows 构建和架构、CPU/GPU/内存/显存、麦克风、采样率、应用版本、游戏区服、设置、日期和执行者。证据使用经参与者同意的测试语料，音频不提交源码仓库。

## 用例

| 用例 | 需求 | 步骤与预期 |
| --- | --- | --- |
| AT-01 首次接入 | FR-001/003/004 | 干净环境安装，选择实体输入，把虚拟麦克风设为系统默认录音/通信输入，按需设置两目标应用；本地录音和目标应用均接收到变声 |
| AT-02 配置复用 | FR-004/008 | 分别重启产品、目标应用和电脑，设备不变；配置保留，产品就绪后直接使用；外部改变默认设备时记录处理方式，不宣称强制覆盖 |
| AT-03 腾讯会议 | FR-002/003、NFR-002/003 | 双端测试，远端确认女声效果和内容；测试静音/恢复、重新入会、默认及调整后的降噪设置；按 PRD 时长连续运行并记录断音与异常 |
| AT-04 瓦洛兰特 | FR-002/003、NFR-002/004 | 在正常反作弊和系统安全配置下，测试队伍/小队语音、按键说话、重进游戏及对端听感；比较变声开启前后相同游戏设置下的 FPS、帧时间、GPU 占用与音频指标 |
| AT-05 离线冷启动 | FR-012、NFR-006 | 模型下载完成后断开网络，重启产品，启动转换、试听、切换已安装模型并由本地录音工具采集；核心处理持续可用，不要求云端登录或推理 |
| AT-06 联网边界 | NFR-006 | 阻断产品及其推理子进程的外网访问，允许会议/游戏正常联网；两场景仍可变声。另检查产品网络行为与实现，确认无音频/声学特征上传；不将目标应用传输语音误判为产品上传 |
| AT-07 模型管理 | FR-012 | 中断下载、校验失败、模型文件缺失、加载失败；给出明确错误，不加载损坏文件；已有模型仍可用，不自动改用云端或原声 |
| AT-08 自然女声音质 | FR-002、NFR-003 | 多位男声、固定中文语料、相同输入条件，盲听原声/转换结果并评分；分别记录本地输出与应用远端输出，核对清晰度、自然度和女声音色符合度 |
| AT-09 延迟与长稳 | NFR-001/002/004 | 测完整本地链路而非仅推理耗时；空载、会议、游戏负载分别报告 p50/p95/最大值、资源峰值和全部欠载/溢出；按 PRD 连续运行 |
| AT-10 故障与静音 | FR-005/007、NFR-005 | 拔麦克风、结束推理进程、模拟过载、睡眠唤醒；按候选故障静音策略核对输出，无自动原声旁路；另外记录第三方应用是否自行切换实体输入 |
| AT-11 发布安装链 | FR-009 | 用正式发布路径在支持的 Windows 11 配置安装、更新、回退、卸载；不要求测试签名或降低安全设置；卸载后普通麦克风可用，无残留失效默认设备影响用户录音 |
| AT-12 易用性 | NFR-007 | 首次使用者按文档完成安装、模型获取、输入配置和测试通话；分别记录各步骤用时、失败点和是否需要工程师协助 |

## 发布前证据清单

- AT 用例结果、缺陷编号和复测证据；未测项保持“未测试”。
- 明确最低/推荐配置与不支持的环境；当前本机硬件读取被拒绝，不能作为已知测试基线。
- 模型、音色、推理依赖、虚拟设备组件的来源、版本及分发依据；下载模型并不自动解决分发权问题。
- 可复现构建、安装包校验值、适用的签名验证、使用说明、离线说明、更新和恢复方法。
- 已知限制、支持应用版本、问题反馈渠道；收费和开源方式另行决定。

## 首轮执行顺序

先 AT-01 验证链路，AT-05/06 验证离线边界，AT-08/09 验证核心效果与性能；再完成两应用实测与安装恢复。任何核心指标失败，记录实际结果并回到方案/需求评审，不自行降低阈值。

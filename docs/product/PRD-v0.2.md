# v0.2 需求：真实音色、自定义训练与首次配置向导

日期：2026-10-25 | 状态：方向已确认，技术选型及量化指标待验证

本文件描述下一版，不代表 v0.1.0 已实现。继承 Windows 11、日常变声本地离线、腾讯会议/瓦洛兰特优先、GitHub 管理和发布等约束。

## 1. 用户已确认

- 提升转换后的人声真实感，贴近真人说话。
- 支持用户录制约 10–20 分钟目标音色素材，等待训练后得到可选择的专属音色。
- 允许用户主动选择云端训练；日常变声必须离线。
- 提供“游戏低延迟”和“会议高音质”两种模式。
- 面向完全不了解音频软件的用户，在本软件内尽可能完成驱动、模型、环境配置。

## 2. 产品边界

“自然度”是像真人说话，“相似度”是像目标说话者，二者分别评估。素材应来自目标音色；用户录自己的原声通常学到自己的音色，不能仅凭男声素材承诺训练出指定女声。素材需来自用户本人或获得使用许可的说话者。

10–20 分钟是录制引导的候选有效语音时长，不保证任意噪声素材均可训练成功。训练阶段可下载依赖；日常推理、读取专属音色和切换模式不能依赖云端在线验证。云训练是逐任务显式选择，不自动上传录音，不因本机训练失败自动改云端。

## 3. 两种模式

| 模式 | 目标 | 候选技术策略 | 待验证 |
| --- | --- | --- | --- |
| 游戏低延迟 | 保持交流及时，提升自然度 | 小分块、较少前瞻、低开销流式引擎 | 完整本地延迟、游戏帧时间、稳定性与自然度 |
| 会议高音质 | 优先音色细节和真实感，仍可正常对话 | 较大上下文或更高质量后端 | 可接受对话延迟、会议降噪影响、资源占用 |

两模式可以使用同一引擎的不同配置，也可以采用不同引擎；不能只改变 UI 标签。是否共享同一训练产物必须实测，不能假定 RVC、Beatrice、Seed-VC 模型互通。

候选指标：游戏模式本地链路 p95 ≤ 150 ms，会议模式 ≤ 250 ms；这些是提案，需同一硬件、同一语料试用后确认。自然度目标应同时满足绝对评分和相对 v0.1 的提升，不能靠增加不可接受延迟取得评分。

## 4. 音色与训练需求

| ID | 优先级 | 需求 | 验收 |
| --- | --- | --- | --- |
| V2-A01 | P0 | 经筛选的真人感女声预置 | 至少一个来源和分发依据明确的女声；中文盲测优于 v0.1；清晰度、自然度、相似度独立记录 |
| V2-A02 | P0 | 游戏/会议模式 | 界面说明延迟和资源取舍；实测配置确实不同；不支持的模型/硬件明确提示，不隐式改云推理 |
| V2-A03 | P0 | 录制向导 | 设备检测、试听、分段朗读提示、有效时长进度；支持暂停、补录、回听与删除，避免要求用户自行整理文件 |
| V2-A04 | P0 | 素材质检 | 检查静音、削波、过低电平、有效时长、明显噪声/多人素材；给出具体重录建议；质量不足不得显示“可训练” |
| V2-A05 | P0 | 自定义训练任务 | 硬件和磁盘检查、推荐设置、阶段进度、取消、失败重试、可恢复阶段记录；训练失败不破坏已有音色 |
| V2-A06 | P0 | 主动选择云训练 | 上传前展示服务方、素材范围、存储/删除政策、费用估计；用户确认后上传；取消/超时/失败/删除均有状态；供应商和预算未定，当前仅需求 |
| V2-A07 | P0 | 音色入库与离线使用 | 下载/导出校验后的模型，命名并试听，保存到“我的音色”；离线冷启动可选、可变声；升级失败保留旧版本 |
| V2-A08 | P0 | 训练结果验收 | 使用未参与训练的中文语料，比较清晰度、自然度、目标相似度；失败提示具体原因，不把训练任务完成当作音质通过 |

推荐流程：新建音色 → 说明素材属于谁 → 录制/导入 → 自动质检 → 补录 → 选择本地或云端训练 → 预览/对比 → 命名保存 → 日常选择并离线使用。

本地训练是拟支持选项，GPU 厂商/显存最低要求经选型确定；不承诺普通无独显电脑可以高效训练。取消至少能够停止当前工作、避免继续扣费/上传，是否可从任意步骤断点恢复取决于后端。

## 5. 首次配置向导

用户只需理解“我的麦克风”“对方听到的声音”“我的耳机”，不以 CABLE Input/Output、VST、CUDA、采样率作为必填知识。

| ID | 优先级 | 需求 | 验收 |
| --- | --- | --- | --- |
| V2-B01 | P0 | 自动环境检查 | 系统、架构、CPU/GPU、可用空间、网络、驱动和模型状态；每项显示可用/需处理/不支持及下一步 |
| V2-B02 | P0 | 驱动准备 | 在软件内说明用途，获取已核验的官方包，校验来源/签名后启动安装；用户处理必要 UAC；检测真实设备而非仅看进程退出码 |
| V2-B03 | P0 | 重启续接 | 保存向导阶段；需要重启时清楚提示，不强制重启；重开后自动检测并继续，避免重复安装 |
| V2-B04 | P0 | 模型一键准备 | 推荐可用音色及模式；显示体积、空间、进度、失败原因；支持重试/可行时续传；验签/校验成功才启用 |
| V2-B05 | P0 | 隐藏环境复杂度 | 运行库随包或按需自动获取到应用管理目录，用户无需安装 Python、执行命令或配置环境变量 |
| V2-B06 | P0 | 引导路由与闭环测试 | 选择实体麦克风/耳机，内部映射虚拟线缆；检测输入和变声输出；引导系统及应用选择；不能因本地电平变化就宣称远端通话通过 |
| V2-B07 | P0 | 修复与卸载 | 可重新检测、修复缺失组件；卸载说明恢复系统输入，不静默移除被其他软件使用的共享驱动 |
| V2-B08 | P1 | GitHub 更新入口 | 显示版本及更新说明，校验包后更新，可回退；更新不破坏已训练音色 |

状态机：检查 → 需要处理 → 下载 → 校验 → 安装/导入 → 需要重启（可选）→ 路由测试 → 就绪。每一步有进行中、成功、失败、取消状态，失败保留可读错误与重试入口。

“软件内操作”允许 Windows UAC 和上游必须展示的安装界面。自研驱动或取得再分发授权前，不把第三方包私自捆绑；下载及启动安装路线须遵守供应商条款。目标为无需用户手动解压、找驱动 EXE 或填写模型路径。

候选易用性验收：5 名首次用户中至少 4 名不依赖工程师和命令行完成配置；下载等待和重启耗时单独记录；断网、磁盘不足、拒绝 UAC、重启后续接各跑一次。

## 6. 技术候选与证据

- RVC 支持小数据量目标音色训练，官方推荐至少 10 分钟低噪语音；适合作为“录制→专属音色”候选，但须验证实时链路、中文、依赖和模型分发。https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI
- Seed-VC 提供零样本转换及实时支持，可用作短录音参考路线的对比；当前用户优先训练路线。原仓库已归档，维护和集成风险需计入选型。https://github.com/Plachtaa/seed-vc
- 当前 Beatrice 仍作为基线；其官方音色不等于已经满足用户期望的真人感。更换模型或引擎必须做同语料盲测，不能用宣传片代替。https://prj-beatrice.com/
- VB-Audio 区分使用和分发条款，软件内安装流程与捆绑授权需分别确认。https://vb-audio.com/Services/licensing.htm

## 7. 验证与交付拆分

1. 音质 PoC：当前基线与至少两条候选配置，在固定中文语料和同硬件上测自然度、清晰度、相似度、p95 完整延迟、游戏负载；确定引擎而不是预先承诺某模型最好。
2. 配置向导：先把初版驱动/模型准备改为可恢复步骤，使用新用户验证；与算法选型可独立推进。
3. 自定义音色：录制质检 → 本地训练验证 → 模型入库离线使用；再接入经确认的可选云训练服务。
4. 模式联调：专属音色在两模式分别验收，记录支持矩阵、硬件和失败恢复。

发布范围按 GitHub Issues 追踪；当前只对齐需求，不因本文件创建而宣称 v0.2 已开发。

## 8. 剩余决策

- 期望的女声风格与可合法使用的试听参考；先以自然中文成年女声作为讨论起点。
- 云训练服务方、单音色费用上限、可接受等待时间及素材保留/删除政策。
- 本地训练硬件覆盖及是否要求无独显电脑使用云训练产物进行实时变声。
- 两模式的延迟阈值和自然度评分在 PoC 后确认；声音素材训练时长不是质量承诺。

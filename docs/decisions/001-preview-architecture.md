# ADR-001：初版离线 AI 与发布路线

日期：2026-10-25 | 状态：已实施的工程选择，非性能验收结论

用户要求直接实现初版、在个人 GitHub 管理与发布；未进一步指定硬件。选择 CPU 可运行的 Beatrice 官方 VST3，通过 Pedalboard 标准宿主运行，Python/Tk 提供中文 UI，PortAudio/WASAPI 提供采集与输出。以 VB-CABLE 作为外部虚拟端点，避免首版自研驱动成为阻断。

选型理由：已有本地流式转换、CPU 路线、可验证的标准插件接口；不调用需独立授权的私有推理库。模型禁止再分发，因此使用官方直接下载与用户条款确认，不镜像到 GitHub，不在安装包夹带模型。宿主依赖 Pedalboard 的 GPL-3.0，当前项目以兼容 GPL-3.0 发布。

版本固定：Beatrice VST3 2.0.0-rc.3、官方模型 1（2.0.0-rc.0）；下载哈希写入 assets.py。初版默认 Corpus 女声，UTAU 为另一选项；中文自然度仍待验证。

代价：首次额外安装驱动、下载模型；模型和音色适用上游条款；不是自有完整引擎；当前程序无代码签名，没有原生插件进程隔离和设备自动恢复。以后增加独立引擎、商业分发或驱动捆绑必须重新评审依赖及授权。

发布：GitHub Actions 测试并打包，版本标签生成预发布 Release。真实应用兼容与完整延迟不足时保持预览标识，不宣称正式版完成。

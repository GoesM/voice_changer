# ADR 002：隔离本地 RVC 训练与实时引擎

日期：2026-10-25。状态：实验性实现，待真人语料和目标应用验收。

用户选择 10–20 分钟目标声音素材训练、日常离线、游戏/会议两模式。本版只做本地训练，云端仅显示开发中。

现有 Beatrice 模型与 RVC 不互通。因此保留官方 Beatrice CPU 路线，新增 Applio 3.7.0（固定提交 a864a1dc5aca33386753c40c192feac53ca71682）的独立 Python 3.12 环境。uv 与源代码 ZIP 校验 SHA-256；Python 由 uv managed Python 安装；依赖版本锁定于 engine-requirements.txt。上游基础模型按其下载逻辑获取，不镜像到本仓库；其 URL 仍是上游可变资源，尚不具备完整权重哈希锁定，应作为供应链改进项。

训练由子进程执行预处理、特征提取、训练与索引生成。适配器强制检查上游 subprocess 返回码，避免上游 CLI 只打印失败但退出码为零时误报。只有完整导出并通过离线模型加载、自检才入库。训练检查点留在上游 logs，录音与导出模型留在应用私人数据目录。已就绪音色不允许原地重训，保护现有可用模型。

实时推理在独立进程执行，使用固定长度 float32 管道通信，不开启本地 HTTP 监听端口；日志走 stderr。Worker 在模型加载前关闭 Python socket 连接并启用 Hugging Face 离线选项，缺失资源报错，不联网补齐。音频线程使用有界队列，超时/失效输出静音。

游戏模式 100 ms 分块、0.5 秒上下文、0.3 检索；会议模式 200 ms 分块、2 秒上下文、0.75 检索。两个模式共享同一训练产物。参数方向不等于已测性能，尤其 100 ms 分块本身已占较大延迟预算。无 CUDA 时明确拒绝自定义路线，不切到云端或原声。

驱动经官方直链下载、固定哈希和 Authenticode 验签后，用户通过 UAC 启动官方安装器。设备是否可用以实际 WASAPI 枚举为准，不以安装器已启动视为安装成功。第三方驱动不捆绑，Windows 重启由用户执行。

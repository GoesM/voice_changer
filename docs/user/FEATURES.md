# 功能介绍

[返回首页](../../README.md) · [使用教程](QUICKSTART.md)

| 功能 | 当前表现 |
| --- | --- |
| AI 男声转女声 | 本机 Beatrice 2 VST3 推理；两个官方女声入口，音调/共振峰可调 |
| 多应用复用 | 经 VB-CABLE，首次配置后供应用选择；没有自研驱动 |
| 离线处理 | 首次下载后无需云端推理，没有遥测、账号或音频上传 |
| 首次准备 | 官方下载、进度提示、SHA-256 校验，也可选择已有文件 |
| 试听与静音 | 可选耳机监听，静音不输出语音，异常不自动输出原声 |
| 状态与诊断 | 电平、处理 p95、丢块/欠载统计，导出不含音频的 JSON |
| 本地音色工作室（实验性） | 录音、WAV 导入、试听删除、质量门槛、RVC 训练及离线自检；需要 NVIDIA CUDA |
| 双模式（自定义音色） | 游戏 100 ms / 会议 200 ms 分块，实际上下文和检索参数不同，不代表总延迟 |
| 应用内组件准备 | 官方驱动下载/校验/启动；独立训练环境安装，无需自行安装 Python |
| GitHub 管理 | 源码、Issue、Actions 和 Release 在同一仓库 |

处理 p95 只测一个音频块的计算时间，不代表完整链路延迟。默认女声参数只是试用起点；中文自然度和游戏负载尚待系统测试。

暂未实现：云训练（界面仅显示开发中）、任意外部模型导入、商城、热换参数、设备自动恢复、开机启动、托盘快捷键、自有签名驱动和安装器。首版需要一次外部组件准备，不能宣称零配置。验收状态见 [验证记录](../validation/v0.2.0-alpha.1.md)。

训练完整操作见 [本地音色教程](CUSTOM_VOICE.md)。新音色的自然度和相似度依赖目标素材；当前没有新增已通过真人自然度盲测的女声预置。

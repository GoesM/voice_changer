# 功能介绍

[返回首页](../../README.md) · [使用教程](QUICKSTART.md)

| 功能 | 当前表现 |
| --- | --- |
| AI 男声转女声 | 本机 Beatrice 2 VST3 推理；两个官方女声入口，音调/共振峰可调 |
| 多应用复用 | 经 VB-CABLE，首次配置后供应用选择；没有自研驱动 |
| 离线处理 | 首次下载后无需云端推理，没有遥测、账号或音频上传 |
| 首次准备 | 官方下载、进度提示、SHA-256 校验，也可选择已有文件 |
| 试听与静音 | 可选耳机监听，静音不输出语音，异常不自动输出原声 |
| 状态与诊断 | 电平、处理 p95、丢块/欠载统计，导出不含音频的 JSON |
| GitHub 管理 | 源码、Issue、Actions 和 Release 在同一仓库 |

处理 p95 只测一个音频块的计算时间，不代表完整链路延迟。默认女声参数只是试用起点；中文自然度和游戏负载尚待系统测试。

暂未实现：模型训练、任意人物克隆、商城、热换参数、设备自动恢复、开机启动、托盘快捷键、自有签名驱动和安装器。首版需要一次外部组件准备，不能宣称零配置。验收状态见 [验证记录](../validation/v0.1.0.md)。

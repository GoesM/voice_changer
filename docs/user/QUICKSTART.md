# 下载与开箱配置

[返回首页](../../README.md) · [常见问题](TROUBLESHOOTING.md)

适用 Windows 11 x64。首次需要网络和驱动安装权限。程序包无需 Python，准备完成后变声计算离线运行。

## 1. 下载与安装

前往 [GitHub Releases](https://github.com/GoesM/voice_changer/releases/tag/v0.3.0-alpha.1)，下载 `VoiceChanger-0.3.0-alpha.1-win-x64.zip`，完整解压后运行 `VoiceChanger.exe`。保留 `_internal` 文件夹，勿只复制 EXE。`Source code` 是源码包。

使用 `Get-FileHash .\VoiceChanger-0.3.0-alpha.1-win-x64.zip -Algorithm SHA256` 核对下载页的 `SHA256SUMS.txt`。

当前 EXE 未代码签名。若系统阻止运行，先核对来源及哈希，不要关闭系统安全功能；组织策略阻止时请由管理员评估。

点击应用内“安装虚拟麦克风”。软件从 [VB-CABLE 官网](https://vb-audio.com/Cable/) 下载固定版本驱动，校验 SHA-256 和数字签名后请求 Windows 管理员授权，打开官方安装器。点击 Install Driver，按提示重启。重开软件后自动枚举设备；检测不到时请检查官方安装结果。也可从官网手动安装。

## 2. 准备本地 AI

1. 点击“模型使用条款”和“AI 插件官网”，阅读插件及各音色条款。
2. 勾选同意，点击“下载并配置 AI（约 58 MB）”。直接访问官方服务器，SHA-256 校验后解压。
3. 显示文件已配置后可断网使用；启动时仍进行模型自检，下载完成不会启动麦克风。

手动准备：从官方获取插件和官方模型 1，完整解压。“选择已有插件与模型”中先选 `beatrice_2.0.0-rc.3.vst3` 文件夹，再选模型的 `.toml`，五个 BIN 文件须在其同一目录。

设置、模型和缓存位于 `%LOCALAPPDATA%\VoiceChanger`。默认不存储录音、不上传音频。使用模型需遵守 [官方条款](https://prj-beatrice.com/2.0.0-rc.0-official-model-1-terms)，并非无使用限制的音色。

## 3. 配置声音路由

| 位置 | 选择 |
| --- | --- |
| 本软件：实体麦克风 | 耳机 / USB / 内置麦克风 |
| 本软件：变声输出 | **CABLE Input** |
| 本软件：耳机监听 | 初次先关闭，需要试听时选实体耳机 |
| 会议/游戏：麦克风 | **CABLE Output** |
| 会议/游戏：扬声器 | 正常耳机，不能选 CABLE Input |

Input 是线缆接收声音的播放端，Output 是送出声音的录音端。

Windows 设置 → 系统 → 声音，把默认输入设为 CABLE Output；“更多声音设置”→“录制”可同时设为默认设备和默认通信设备。固定选其他输入的应用还需手动选一次。不要把系统默认扬声器改为 CABLE Input。

选择自然女声，音调先用 +8 半音、共振峰 0，然后“开始 AI 变声”。参数只是起点，效果取决于模型和发声。参数需停止后调整，再启动生效。

## 4. 接入会议和游戏

### 腾讯会议

在音频设置中选择麦克风 CABLE Output、扬声器正常耳机。测试电平并进行双端通话，由另一端确认音色。若声音被压制或断续，对比应用降噪/自动增益设置；选项名称可能随版本变化。

### 瓦洛兰特

在声音/语音聊天设置中选择输入 CABLE Output、输出正常耳机；检查队伍/小队语音和按键说话，用回环或队友测试。本产品不注入游戏、不修改或关闭反作弊。

这两项是优先验证场景，**当前未完成实机通话兼容验收**。问题请提交 [Issue](https://github.com/GoesM/voice_changer/issues)。

## 5. 日常使用

启动程序 → 确认配置 → 开始变声 → 使用目标应用。每次手动开始，程序不自动开机采集。静音影响虚拟输出，停止会关闭本程序音频流。保持程序运行才能变声。

监听使用耳机，避免扬声器反馈；不要重复打开 Windows“侦听此设备”。设备拔出/休眠恢复失败时，重开程序并重新选择设备。第三方应用自行切回实体麦克风仍可能传原声，本软件无法强制控制。

## 6. 更新与卸载

更新：停止旧版，解压新版到新目录，复用用户目录的模型和设置；勿同时运行两版。需要回退时重新运行旧版。

卸载：退出后删除解压目录，需要清理模型时手动删除 `%LOCALAPPDATA%\VoiceChanger`。驱动独立存在，按 VB-Audio 官方方法卸载；先把系统和应用输入切回实体麦克风。

## 6. 本地训练专属音色

点击“素材库 / 朗读采集 / 训练”，按 [本地训练教程](CUSTOM_VOICE.md) 安装独立环境、录制素材并训练。该功能需 NVIDIA CUDA 显卡，日常使用离线。云训练显示“功能仍在开发中....”。

## 7. 素材管理与稿件采集

新建素材集后，点击“原创稿件 · 引导朗读”，逐段录音、试听并确认。40 段稿件已随应用提供，关闭后可继续。[详细操作](MATERIALS_AND_READING.md)。Release 的 ReadingKit 是可独立阅读的文字包，不含明星录音。

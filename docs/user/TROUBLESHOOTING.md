# 常见问题

[返回首页](../../README.md) · [配置教程](QUICKSTART.md)

| 问题 | 排查 |
| --- | --- |
| 找不到 CABLE Input | 安装官方 x64 VB-CABLE，按提示重启并重开程序 |
| 本地有电平，对方无声 | 输出 CABLE Input，应用输入 CABLE Output；检查运行和静音状态 |
| 对方听到原声 | 应用仍选实体麦克风或自行切换输入，检查应用设置 |
| 重复声音/啸叫 | 关闭重复监听，使用耳机，不要把系统默认扬声器设为 CABLE Input |
| 下载 403/超时 | 检查能否访问官方 storage.prj-beatrice.com；重试或从官网手动下载完整文件 |
| 校验失败 | 不会加载不匹配文件；重试，或提交 Issue 等待核验，勿关闭校验 |
| 插件加载失败 | 仅支持官方 2.0.0-rc.3 Windows 插件，保持 Contents 目录完整 |
| 模型自检失败 | 选择官方模型 1 的 TOML，检查同目录五个 BIN 文件；重新下载 |
| 音频格式不支持 | 检查设备 48 kHz 支持，关闭其他独占采集程序；首版不自动适配其他采样率 |
| 卡顿、断音 | 查看处理 p95/丢块/欠载，对比游戏负载；尚无完整实测最低配置 |
| 换设备后失败 | 停止、刷新或重开；同名设备先在 Windows 重命名 |
| 停止后无声音 | 停止会停供音，需要原声时在应用中显式选择实体麦克风 |
| 调参数未生效 | 停止后修改，再启动 |

导出诊断并检查内容后，连同版本和复现步骤提交 [GitHub Issue](https://github.com/GoesM/voice_changer/issues)。包含设备名称及统计，不包含音频；不要提交私人录音。

# 素材库与原创稿件采集

适用于 v0.3.0-alpha.1。[下载应用](https://github.com/GoesM/voice_changer/releases/tag/v0.3.0-alpha.1) · [训练教程](CUSTOM_VOICE.md)

本版支持用户自己的录音和有权使用的素材。**没有附带明星录音。** Release 中的 ReadingKit 是原创文字稿件，不是语音模型或音频包；应用已经内置同一份稿件，不必另外导入。

## 1. 管理一个说话人的素材

主界面点击“素材库 / 朗读采集 / 训练”。确认素材使用授权后，新建素材集；每个素材集只放同一说话人的声音。以后直接从下拉列表选择，不需要记住项目文件夹路径。旧版创建的项目也会显示在列表中。

- **导入 WAV 素材**：支持 16 位 PCM WAV、16–96 kHz、单/双声道。导入会复制文件，不移动原文件。列表保留原文件的名称，显示时长和来源。其他格式请先转换为这一格式，本版不内置 MP3 转码。
- **试听、重命名**：素材名称可以修改，磁盘上的文件标识保持不变。试听需要选择实体耳机。
- **移除**：录音从训练素材中移除，保留在素材集的 `.trash` 文件夹；不会再计入训练时长。已生成的模型不随之删除。
- **复制为新训练项目**：复制已确认素材，开始新的训练版本；不复制模型、检查点或待确认录音。取消时可能留下部分已复制素材，可在素材集列表中查看。
- **重命名素材集**：用于区分说话人或录制批次。名称变化不修改已有录音。

## 2. 跟随稿件录音

选择素材集，点击“原创稿件 · 引导朗读”。稿件共 40 段、4,898 个汉字，覆盖日常陈述、提问、数字、时间、会议和游戏沟通。按每分钟 240–320 字估算约 15–20 分钟，**实际时长取决于朗读速度**。这些是原创自然语言练习，并未经过专业音素覆盖率或模型效果评测。

1. 选择实体麦克风和试听耳机，在安静环境中保持稳定距离，用平常的音色朗读。
2. 先看本段文字及提示，再点击“开始 / 重录本段”。本功能只有点击录音后才采集麦克风。
3. 读完点击“停止录音 / 试听”。录音先存为待确认，不进入训练数据。
4. 点击“试听”，检查是否漏读、说错、被打断或混入其他人声。
5. 满意后点击“确认并下一段”。程序检查时长、削波和按音量估算的有效声音比例，通过后才加入素材库。
6. 可用上一段、下一段或段落列表跳转。跳过不会算作完成；关闭后，下次打开会恢复所在段落、待确认录音和已确认状态。

每段最多录制 3 分钟，到时自动停止，仍需确认。短于约每秒 8 字对应时长的录音、明显削波或有效声音不足一半的录音会被拒绝确认；这些只是工程门槛，不代表内容核对或音质认证。程序不做语音识别，不知道你是否读对了稿件，请先试听。

重录时，旧的已确认录音会一直保留，直到新录音通过确认；确认后替换旧素材，避免同一段重复计时。旧录音移入 `.trash`。删除已确认素材后，对应段落会重新显示未完成。

## 3. 达到训练门槛

返回素材库查看统计：总时长至少 10 分钟、有效声音至少 5 分钟、无明显削波，才允许训练。读完 40 段不等于必然达标；若时间不足，请以自然语速补录清晰语音，不要拖长静音凑时长。

录音、素材管理、稿件显示不需要下载训练环境，也不需要 NVIDIA 显卡。本地训练和本版 RVC 自定义音色推理仍需 CUDA。继续训练的步骤见[本地训练教程](CUSTOM_VOICE.md)。

## 4. 数据和文字包

本地数据位于 `%LOCALAPPDATA%\VoiceChanger\voices\voice_…`：

| 内容 | 位置 |
| --- | --- |
| 确认后可训练的录音 | `recordings` |
| 未确认录音 | `.takes` |
| 移除或替换的录音 | `.trash` |
| 素材显示名称和质检缓存 | `materials.json` |
| 当前段落、确认记录和待确认记录 | `reading.json` |

备份素材集时复制整个文件夹。文字稿件以 CC0-1.0 提供，可以朗读、改编、再分发及用于训练；这不替代具体录音和说话人的使用许可。应用代码保持 GPL-3.0。

Release 同时提供 `VoiceChanger-ReadingKit-0.3.0-alpha.1.zip`，内含便于离线阅读的 `READING.md`、结构化稿件 `reading_zh.json` 和文字许可说明。它不包含用户录音，不需要联网即可阅读。

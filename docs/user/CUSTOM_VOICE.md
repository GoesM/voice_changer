# 录制与训练专属音色

本功能在 v0.2.0-alpha.1 中提供实验性本地 RVC 流程。官方 Beatrice 音色不需要训练，也不需要 CUDA；自定义音色的训练和本版实时推理需要 NVIDIA CUDA 显卡。建议至少预留 15 GB 磁盘空间。不同显存容量的最低配置仍需验证。

## 1. 准备环境

主界面先选择实体麦克风，以及用于试听的实体耳机。停止变声，点击 **录制 / 训练专属音色**，再点击 **安装 / 修复训练环境**。

应用会下载固定版本 Applio、独立 Python、CUDA 依赖和基础模型，保存在 `%LOCALAPPDATA%\VoiceChanger\training-engine`，无需自己安装 Python 或输入命令。首次下载数 GB，请保持联网；下载失败可重试，已校验的组件包会复用。并非所有文件支持断点续传。安装失败可打开日志目录查看 `install.log`。

上游：[Applio](https://github.com/IAHispano/Applio)、[使用条款](https://github.com/IAHispano/Applio/blob/3.7.0/TERMS_OF_USE.md)。依赖、基础模型和音色适用各自许可；模型和驱动不会随本应用压缩包分发。

## 2. 收集目标声音

确认有权使用素材，创建音色项目，点击“开始录音”。可以分多段录制，每段至少 3 秒、最多 20 分钟。点击“停止并保存”结束一段。也可导入 16 位 PCM WAV，单/双声道，16–96 kHz。已有素材会复制到项目中，不移动原文件。

录的是**希望变成的声音**。用自己的男声训练，不能自动得到一个指定女声。建议目标说话者在安静房间自然朗读，保持相同麦克风距离，覆盖疑问、陈述、不同语速和音高，避免音乐、其他人声、长静音及夸张表演。

素材列表支持耳机试听、停止试听和删除。累计总时长至少 10 分钟，其中按音量估算的有效声音至少 5 分钟，无明显削波才可开始训练。建议准备 10–20 分钟清晰语音。检测只判断音量和时长，不能可靠判断说话人数量、混响、内容或自然度。

## 3. 在本机训练

默认 100 轮、batch size 2、40 kHz、RMVPE 音高提取、ContentVec 特征。点击“开始本地训练”，界面依次显示素材预处理、特征提取、训练、导出自检。处理时间取决于显卡、素材及轮数，没有固定分钟数承诺。

可点击“取消当前任务”，等待子进程退出。素材及上游检查点保留；继续已有项目后再次训练，后端会尝试恢复检查点，不能保证从任意步骤精确恢复。断电或强制结束后，重新打开项目再运行即可；旧的“training”状态不代表后台仍在训练。

只有模型和索引均导出、离线加载及合成信号推理自检通过，音色才加入主界面。自检通过说明文件可运行，**不代表自然度通过**。已完成音色不允许原地重训，请新建项目，避免失败覆盖现有音色。

## 4. 选择音色与模式

返回主界面，音色列表中选择新音色。调整音调，启动离线变声，开启耳机监听确认效果。RVC 暂不使用主界面的共振峰参数。

| 自定义音色模式 | 分块 | 上下文 | 检索强度 | 取舍 |
| --- | --- | --- | --- | --- |
| 游戏低延迟 | 100 ms | 0.5 秒 | 0.3 | 缩短分块、减少检索；仍有计算和设备延迟 |
| 会议高音质 | 200 ms | 2 秒 | 0.75 | 更多上下文和目标特征；资源和延迟更高 |

这两个名称描述配置方向，并非音质或总延迟保证。切换需停止后重启。官方 Beatrice 音色仍使用其固定 20 ms 音频分块，不套用 RVC 模式。会议或游戏仍需把麦克风选择为 CABLE Output。

## 5. 数据、失败与云功能

素材和音色存于 `%LOCALAPPDATA%\VoiceChanger\voices`，训练工作文件在 `training-engine\Applio-…\logs`。日志可能包含本地路径，分享前检查。删除项目文件夹可移除录音与已导出音色；要完全删除训练数据，还需删除同名 logs 项目目录。先停止软件，切勿误删其他音色。

推理时禁止 Python 网络连接，缺少基础模型就停止并提示修复，不自动联网下载，不输出原声。训练安装阶段会访问官方依赖及模型源。没有素材上传接口。

**云训练：功能仍在开发中....** 本版不能选购、上传或使用云训练。

显存不足：关闭游戏和其他 GPU 程序后重试。安装失败：查看 install.log，检查空间与网络后修复。训练失败：查看项目 training.log；启动音色失败：查看 inference.log。不要把失败状态理解成音色已可用。
